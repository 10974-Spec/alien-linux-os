Alien OS includes "Alien Store", which is a rebranded and modified version of COSMIC Store by System76.

COSMIC Store is licensed under the GNU General Public License v3.0 (GPL-3.0).
As per the terms of the GPL, the corresponding source code for Alien Store, including all modifications (patches) made by the Alien OS project, is available in this repository under the `packages/alien-store/` directory.

You may build the exact version included in Alien OS by following the instructions in `packages/alien-store/build.sh`.
