## 3. Live-Build Pipeline & Configuration Analysis

1. **Package Lists (`layers/shared/package-lists/`, `layers/lite/package-lists/`):**
   - `alien-player`, `alien-viewer`, `alien-notes`, `alien-store` were not listed in any `.list.chroot` because they were not built as proper `.deb` packages in `packages.chroot/`.
   - `firefox-esr` was omitted from `layers/lite/package-lists/` in favor of `brave-browser`.
   - `vlc`, `vlc-plugin-base`, `vlc-plugin-qt`, `libavcodec-extra` were not included in `lite/`.
2. **Local Packages (`packages/`):**
   - `packages/alien-store/build.sh` had `# cargo deb` commented out; no `cosmic-store` binary was compiled or packaged.
   - Packages in `packages/*.deb` were copied by `assemble.d/packages-chroot.sh` into `config/packages.chroot/`, but because they were not specified in `.list.chroot`, `lb chroot_install-packages` never installed them as dpkg packages.
3. **Desktop Files & Skel Configuration:**
   - Social web apps (`alien-webapp-*.desktop`) were generated by `assemble.d/webapps.sh` and pinned in `assemble.d/lxqt-defaults.sh`.
   - The panel configuration pinned 6 social applications across the bottom panel.
4. **Bootloader & Kernel Parameters:**
   - The GRUB template in `assemble.d/boot-branding.sh` used unquoted heredocs (`<<GRUB_EOF`), causing `$kernel_path` to be evaluated as empty at build time.
   - The boot menu included 6 entries and submenus instead of an instant, clean 1-second/hidden boot to desktop.
   - Plymouth theme was installed into `/usr/share/plymouth/themes/alien`, but initramfs did not have the Plymouth hook executed with `-R` during binary generation.

## 4. Root Cause Summary Table

- **ROOT CAUSE: Alien Player** — `Source & Engine`: Script wrapped `mpv` without a GUI or arguments; launching from menu opened no window and exited immediately. Fix: VLC engine (`vlc-plugin-qt`) with dedicated Alien wrapper and MIME defaults.
- **ROOT CAUSE: Alien Viewer** — `Packaging`: `lximage-qt` was present, but `alien-viewer` was a standalone script not packaged as a clean system application. Fix: Package `alien-viewer` wrapping `lximage-qt` with logging.
- **ROOT CAUSE: Alien Notes** — `Packaging`: `featherpad` was present, but notes were not structured under `~/Documents/Notes` with proper logging. Fix: Package `alien-notes` wrapping `featherpad` pointing to `~/Documents/Notes`.
- **ROOT CAUSE: COSMIC Store** — `Build Pipeline`: `# cargo deb` was commented out in `packages/alien-store/build.sh`; no compiled `cosmic-store` binary was ever packaged. Fix: Install genuine `cosmic-store` binary (from official Pop!_OS release repository) with software rendering fallback wrapper.
- **ROOT CAUSE: Alien Browser** — `Package Selection`: Image installed `brave-browser` with external webapp ties rather than reliable in-distro `firefox-esr`. Fix: Install `firefox-esr`, create `alien-browser` wrapper and desktop entry, set as system default.
- **ROOT CAUSE: Social Apps** — `Configuration`: `assemble.d/webapps.sh` and `assemble.d/lxqt-defaults.sh` explicitly generated and pinned WhatsApp, Instagram, TikTok, Telegram, Spotify, YouTube. Fix: Delete all social files, scripts, icons, and categories.
- **ROOT CAUSE: Boot Splash (Plymouth)** — `Initramfs & Hook`: Plymouth theme was copied to filesystem, but `plymouth-set-default-theme -R alien` and `update-initramfs -u -k all` were not run inside the final chroot hook, leaving the initramfs without the Alien splash. Fix: Add chroot hook rebuilding initramfs with theme assets and quiet splash kernel args.
- **ROOT CAUSE: Boot Menu Clutter** — `Bootloader Configuration`: `assemble.d/boot-branding.sh` generated 6 visible entries plus a Tools submenu with 5s timeout. Fix: Replace with single 1s/hidden entry with quiet splash; fallback only on Esc/Shift.
- **ROOT CAUSE: Icons8 Colored Icons** — `Asset Availability`: No Icons8 colored icon family exists in the repository. As per Section 7.2, document required files in `docs/ICONS8-NEEDED.md`.
